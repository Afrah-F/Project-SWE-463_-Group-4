# Mizania — Student Budget Tracker

**SWE 463 | Group 04 | Phase 2**

Mizania is a Flutter application designed to help students manage monthly budgets, track expenses, set savings goals, and view spending reports.

## Flutter Starter

The Phase 2 starter includes a Welcome screen, Material 3 theme, and placeholder navigation between Home, History, Budgets, Savings, Reports, and Settings.

## How to Run

```bash
flutter pub get
flutter run -d chrome
```

## Project Structure

- `lib/main.dart` — Application entry point and navigation.
- `test/` — Widget tests.
- `pubspec.yaml` — Flutter configuration and dependencies.

## Packages

The current starter uses Flutter's built-in Material widgets. Provider, Firebase Authentication, SQLite, and other feature-specific packages are planned for Phase 3.

## AI Assistance

ChatGPT was used for design review, documentation refinement, and Flutter debugging. Builder.io was used for AI-assisted UI prototyping. The team reviewed the submitted work.
